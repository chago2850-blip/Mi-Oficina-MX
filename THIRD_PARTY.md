# Componentes de terceros

Mi Oficina MX se distribuye bajo la **GPL-3.0-or-later**. Incluye estas bibliotecas libres, todas compatibles con la GPL-3.0:

| Componente | Uso | Licencia |
| --- | --- | --- |
| [Electron](https://www.electronjs.org/) | Contenedor de escritorio multiplataforma | MIT |
| [HyperFormula](https://github.com/handsontable/hyperformula) | Motor de fórmulas de Calcula Datos | GPL-3.0-only |
| [ExcelJS](https://github.com/exceljs/exceljs) | Leer y escribir .xlsx | MIT |
| [Apache ECharts](https://echarts.apache.org/) | Gráficos | Apache-2.0 |
| [docx](https://github.com/dolanmiu/docx) | Escribir .docx | MIT |
| [mammoth](https://github.com/mwilliamson/mammoth.js) | Leer .docx | BSD-2-Clause |
| [JSZip](https://stuk.github.io/jszip/) | Archivos .zip de Office | MIT o GPL-3.0 |
| [PptxGenJS](https://github.com/gitbrent/PptxGenJS) | Escribir .pptx | MIT |
| [pptxtojson](https://github.com/pipipi-pikachu/pptxtojson) | Leer .pptx | MIT |
| [PDF.js](https://mozilla.github.io/pdf.js/) | Mostrar PDF (PapelPDF) | Apache-2.0 |
| [pdf-lib](https://pdf-lib.js.org/) | Editar PDF (PapelPDF) | MIT |
| [qpdf-wasm](https://github.com/neslinesli93/qpdf-wasm) | Cifrar y comprimir PDF | Apache-2.0 |
| [Tesseract.js](https://tesseract.projectnaptha.com/) | OCR sin conexión | Apache-2.0 |
| [Temml](https://temml.org/) | Ecuaciones (LaTeX → MathML) | MIT |
| [jsdiff](https://github.com/kpdecker/jsdiff) | Comparar documentos | BSD-3-Clause |
| [webm-muxer](https://github.com/Vanilagy/webm-muxer) | Exportar presentaciones a video | MIT |
| [officecrypto-tool](https://github.com/zurmokeeper/officecrypto-tool) (con crypto-js, xml2js y cfb) | Cifrar y abrir archivos de Office con contraseña | MIT · Apache-2.0 (cfb) |
| [word-extractor](https://github.com/morungos/node-word-extractor) | Abrir .doc de Word 97-2003 | MIT |
| [esbuild](https://esbuild.github.io/) | Empaquetar la interfaz (solo desarrollo) | MIT |

**PapelPDF** es del mismo autor y se publicó originalmente bajo MIT; dentro de esta suite se distribuye bajo la GPL-3.0.

Los logotipos, íconos, temas y plantillas de Mi Oficina MX son originales (GPL-3.0). No se usa ningún nombre, ícono, fuente, plantilla ni texto de Microsoft. "Microsoft Office", "Word", "Excel" y "PowerPoint" son marcas de Microsoft Corporation y solo se mencionan para describir la compatibilidad de formatos.
